# drillslug

Drill encode/decode helpers for slug payloads in pipelines.

**Site:** https://theworker02.github.io/drillslug/

## Install / run

```bash
git clone https://github.com/theworker02/drillslug.git
cd drillslug
node src/cli.js
node --test
```
